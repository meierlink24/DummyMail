# Dummy-Usr

**Dummy-Usr** is a Firefox browser extension designed to generate temporary or long-term dummy email addresses. It's perfect for users who want to protect their privacy and avoid spam, newsletters, or promotional emails. You can define how long your dummy account should last—use it for one-time signups or maintain anonymity over longer periods.

---

## 🧩 Features

- ⚡ Instantly create disposable email addresses
- ⏱️ Set custom expiration times (short-term or long-term)
- 🛡️ Keep your primary inbox clean and safe
- 🔗 Simple UI integrated into Firefox
- 📥 Read incoming messages directly from the extension
